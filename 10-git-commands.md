# Git Commands

1. `git config --global user.name "fuadinadhif"`: setup username
2. `git config --global user.email "nadhiffuadi@gmail.com"`: setup user email
3. `git init`: mengubah folder biasa menjadi folder git
4. `git add .`: menambahkan SEMUA (.) folder kita ke staging area
5. `git commit -m "commit message"`: menyimpan perubahan file dan folder ke repository LOKAL
6. `git remote add origin url`
7. `git push -u origin main`
